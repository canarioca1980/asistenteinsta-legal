Política de privacidad de AsistenteInsta

Última actualización: 15 de octubre de 2026

1. Responsable

AsistenteInsta es una aplicación personal para gestionar y analizar información de Instagram. Contacto: mar.martel.penaos@gmail.com.

2. Datos tratados

La aplicación puede procesar los mensajes recibidos, identificadores de Instagram y datos necesarios para gestionar las conversaciones, según los permisos concedidos y las funciones activadas por el usuario.

3. Finalidad

Los datos se utilizan para gestionar mensajes y ofrecer funciones de asistencia mediante inteligencia artificial.

4. Tratamiento y conservación

Los datos pueden almacenarse en la base de datos de la aplicación y procesarse mediante Ollama. Se conservarán únicamente durante el tiempo necesario para la finalidad indicada o hasta que se solicite su eliminación.

5. Comunicación a terceros

La aplicación utiliza los servicios de Meta para las funciones de Instagram. No se venderán los datos personales. Cualquier otro tratamiento o transferencia deberá describirse aquí si corresponde.

6. Derechos y contacto

Para consultar, rectificar o solicitar la eliminación de datos, escribe a mar.martel.penaos@gmail.com.

7. Seguridad

Se aplicarán medidas razonables para proteger los datos tratados por la aplicación.
